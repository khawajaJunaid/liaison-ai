    The pipeline is a list. Each box is a registered step that declares what it needs and what it provides. Reorder, drop or add steps without touching the agent:
    LEASE_AGENT_LEASE_STEPS=read_pdf,extract_fields,match_unit,validate_rules,self_check
    After a person overrides a field, only the dashed-bracket steps run again. The PDF is not re-read. The human gate is outside the pipeline: accept, reject and override are separate calls, so the pipeline never accepts a lease on its own.
